BALANCE DIGITAL - BACKEND

1. Abre una terminal dentro de esta carpeta.
2. Ejecuta: npm install
3. Abre el archivo .env y coloca tu contraseña de MySQL en DB_PASSWORD.
4. Ejecuta: npm run dev
5. Prueba en el navegador: http://localhost:4000/api/salud

La base de datos esperada se llama: balance_digital
