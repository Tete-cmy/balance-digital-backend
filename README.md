# Balance Digital - Backend

Backend del sistema de finanzas personales Balance Digital.

## Descripcion

Balance Digital es una aplicacion web orientada a la administracion de finanzas personales.

Este repositorio contiene los servicios del servidor, la logica de negocio y la comunicacion con la base de datos.

## Tecnologias

- Node.js
- Express
- TypeScript
- MySQL
- JWT

## Funcionalidades principales

- Autenticacion de usuarios.
- Gestion de informacion financiera.
- Comunicacion con la base de datos.
- Servicios API para el frontend.
- Gestion de configuraciones del usuario.

## Arquitectura

El proyecto esta dividido en dos repositorios:

- Frontend: React, TypeScript y Vite.
- Backend: Node.js, Express, TypeScript y MySQL.

## Instalacion

1. Clonar el repositorio.
2. Instalar dependencias con npm install.
3. Configurar las variables de entorno necesarias.
4. Consultar los scripts disponibles en package.json para iniciar el servidor.

## Seguridad

Las credenciales y variables privadas deben mantenerse fuera del repositorio.
